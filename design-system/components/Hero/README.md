# Hero

Khối mở đầu trang bo `radius-xl` trên nền `surface-alt`: overline, tiêu đề lớn, đoạn dẫn, hai nút và vùng hình bên phải.

- **Cung cấp:** `<section class="lm-hero">` gồm cột chữ (`lm-hero__overline`, `lm-hero__title`, `lm-hero__lead`, `lm-hero__ctas`) và `lm-hero__media` (ảnh sản phẩm hoặc khối hình cam).
- **Tô cam** một cụm từ quan trọng trong tiêu đề bằng `<em>` (màu `brand-deep`).
- Một nút chính `--lg` và tối đa một nút `--secondary`.
- Dưới 734px hero xếp một cột, tiêu đề 40px.
- **Không nên** dùng ảnh nền phủ kín toàn khối; giữ nền sáng và để hình nằm gọn bên phải.
