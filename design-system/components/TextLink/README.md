# TextLink

Link chữ màu `brand-deep`, đậm 600, gạch chân khi hover; thêm mũi tên khi dẫn sang trang khác.

- **Cung cấp:** `<a class="lm-link">`; thêm `lm-link--arrow` để có ` →` trượt nhẹ khi hover.
- **Dùng** link mũi tên ở cuối section ("Xem tất cả gói cước →"); link thường trong câu.
- **Không nên** dùng `brand` (cam sáng) cho chữ link: không đủ độ tương phản trên nền trắng.
