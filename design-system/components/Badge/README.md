# Badge

Nhãn nhỏ bo tròn để gắn ưu đãi, thời hạn hoặc trạng thái lên card và tiêu đề.

- **Cung cấp:** `<span class="lm-badge">` với chữ ngắn (1–3 từ). Biến thể: `--solid` (nền `brand`, cho "Phổ biến nhất"), mặc định (nền `brand-soft`), `--neutral`, `--success`, `--info`.
- **Dùng** tối đa một badge `--solid` trong mỗi nhóm card.
- Badge trạng thái luôn có chữ, không chỉ dựa vào màu.
