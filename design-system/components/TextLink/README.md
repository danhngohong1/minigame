# TextLink

A plain `link`-colored text link, underlined only on hover; add a chevron when it leads to another page.

- **Provide:** `<a class="lm-link">`; add `lm-link--chevron` to append a non-breaking space and `›`.
- **Use** chevron links for "go further" actions under sections ("Compare all models ›"); plain links inside sentences.
- **Don't** use arrow icons, bold, or `accent` for links. On `tile-dark-bg` set color to `tile-dark-link`.
